## (b) Identifiants Contradictoires

- **SF-04** (agrégats intercommunaux)
  - Ancien : « Aucun agrégat intercommunal ; toute action vérifie le contexte côté serveur. »
  - SFD : « organisateur : seuls agrégats globaux sans PII des autres communes » (Écran 10) ; « Une demande multi-communes est comptée une fois dans les statistiques globales » (§2.1).
- **SF-08** (clôture globale)
  - Ancien : « Interdire la clôture si une commune participe encore activement » ; « Un gestionnaire communal ne peut clôturer globalement un événement partagé » ; acteur : Superadministrateur SaaS.
  - SFD : « Clôture globale normale : action manuelle de l'organisateur une fois toutes les participations clôturées ; CWS peut forcer avec justification » (§6.2) ; « Clôture forcée autorisée malgré participations actives » (SCR-052).
- **SF-11** (périodes et catégories)
  - Ancien : « Saisir [...] périodes souhaitées » ; catégories « résident, agriculteur, professionnel, prestataire/livraison, aide à un proche, intervention d'urgence, autre ».
  - SFD : « Aucune date demandée au citoyen : elle est fixée par l'instructeur » (§4.2) ; « Motif texte obligatoire » (SCR-021), sans liste de catégories.
- **SF-18** (SMS)
  - Ancien : « SMS non connecté en V1 ».
  - SFD : « Les SMS sont inclus dans le code V1 mais désactivés pendant les tests par défaut » (§7.1).
- **SF-23** (journal des contrôles)
  - Ancien : « Conserver minimum : identifiant titre, date/heure, résultat, point de contrôle si connu ; transmettre journaux hors ligne au retour du réseau ».
  - SFD : « Aucun historique de scans, passages ou géolocalisation ; seuls logs techniques d'activation/synchronisation nécessaires » (§7.3) ; « pas de scan log » (Écran 34).
- **Q17-01** (révocation globale du titre)
  - Ancien (proposition de travail) : « Ne pas donner à une commune le pouvoir de révoquer les droits des autres ; définir une action globale distincte. »
  - SFD : « La commune organisatrice peut révoquer globalement un laissez-passer accessible dans son périmètre » (§2.1) ; SCR-033 : « Révocation globale réservée à organisateur sur dossier accessible ou CWS ».
