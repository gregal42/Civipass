# DM-012 — Mode « Toute la durée de l'événement »

- **Identifiant** : DM-012
- **Thème** : Validité temporelle
- **Statut** : Validée
- **Validation** : Cadrage produit — décision du commanditaire (message de lancement du LOT TECH-02.1) ; date de validation non renseignée
- **Décisions remplacées** : Aucune.

## Contexte

Mode simple de configuration d'une zone.

## Décision

La validité « toute la durée de l'événement » ne nécessite pas de créneaux.

## Conséquences fonctionnelles ou techniques

- Ce mode n'est associé à aucun créneau.
- Les droits sont bornés par la période de l'événement.
