# DM-027 — Aucun héritage permanent entre zones

- **Identifiant** : DM-027
- **Thème** : Opérations groupées
- **Statut** : Validée
- **Validation** : Cadrage produit — décision du commanditaire (message de lancement du LOT TECH-02.1) ; date de validation non renseignée
- **Décisions remplacées** : Aucune.

## Contexte

Corollaire de DM-026.

## Décision

Aucun héritage permanent : modifier une zone après l'application ne modifie pas les autres.

## Conséquences fonctionnelles ou techniques

- Pas de modèle « configuration partagée » ni de lien modèle→zones.
