# DM-026 — Configurations indépendantes après application

- **Identifiant** : DM-026
- **Thème** : Opérations groupées
- **Statut** : Validée
- **Validation** : Cadrage produit — décision du commanditaire (message de lancement du LOT TECH-02.1) ; date de validation non renseignée
- **Décisions remplacées** : Aucune.

## Contexte

Éviter tout couplage entre zones après une opération groupée.

## Décision

Les configurations appliquées deviennent indépendantes : chaque zone dispose de ses propres créneaux.

## Conséquences fonctionnelles ou techniques

- Chaque zone reçoit ses propres lignes de créneaux (copie), sans référence à une source.
