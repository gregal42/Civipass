# DM-013 — Mode « Périodes spécifiques »

- **Identifiant** : DM-013
- **Thème** : Validité temporelle
- **Statut** : Validée
- **Validation** : Cadrage produit — décision du commanditaire (message de lancement du LOT TECH-02.1) ; date de validation non renseignée
- **Décisions remplacées** : Aucune.

## Contexte

SFD SCR-018 : « Ajouter/éditer créneau ».

## Décision

La validité « périodes spécifiques » nécessite au moins un créneau pour être opérationnelle. Plusieurs créneaux peuvent être définis.

## Conséquences fonctionnelles ou techniques

- Une zone en périodes spécifiques sans créneau n'ouvre aucun droit.
- Une zone peut porter zéro à plusieurs créneaux.
