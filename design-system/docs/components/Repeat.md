# Repeat (`cp--repeat`) — PROPOSITION LOT 03

Lignes répétables (immatriculations). Targets `list`, `template` (jeton `__INDEX__`), `add`, `status` ; actions `add`, `remove`.
La dernière ligne n’est pas supprimée mais vidée. Après ajout, le focus va sur le nouveau champ ; après retrait, sur « Ajouter ». Chaque action est annoncée (`aria-live`).
Valeurs : `noun` (« plaque »), `max` (0 = sans limite d’interface ; le serveur garde ses protections anti-abus).
