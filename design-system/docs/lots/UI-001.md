## Composants ajoutés au lot UI-001

IconButton, ActionMenu, MobileMenu, Banner, Select, SearchField, Check, FileUpload, ZoneSelect, DataTable, FilterBar, Pagination, Modal, ConfirmPanel, RequestCard, PassCard, QrCode, Validity, Authorization, Documents, CommuneDecisions ; variantes `danger` (Button), e-mail / téléphone / validation / désactivé / lecture seule (Field) ; menu du compte et rôle visible en compact (AppShell) ; contrôleurs `cp--modal`, `cp--toggle`, `cp--file-upload`, `cp--zone-select` ; 18 icônes.

Les données du prototype sont fictives. `prototype/proto.js` simule le serveur ; il ne fait pas partie du design system.
